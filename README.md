# Word Bites Practice
A solo practice clone of GamePigeon Word Bites for iPhone/iPad (add to Home Screen). 8x9 board, single and two-letter tiles, 80-second rounds, real-game length scoring, replayable board seeds, stem drill and practice-with-hints modes.
Word list: ENABLE (public domain), 105,145 words of 3-9 letters. GamePigeon's real list is Collins-based and its board algorithm is not public, so this is an approximation.
